# Gestão de Condomínio (nome provisório)

Sistema web para condomínios pequenos com síndico morador: cobrança com comprovante e recibo, chamados com prova de resolução, comunicados e feed de transparência.

**Transparência com prova:** toda ação relevante fica registrada com autor, data e prova, e ninguém consegue apagá-la.
